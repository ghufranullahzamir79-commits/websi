# Helalune

A beauty and fashion storefront in HTML and CSS. The edit follows the six rooms of the maison, in order: luxury cosmetics, care tools, everyday glow, Sara’s imitation jewelry, the storefront, and the glow ritual.

Shopping, filters, the bag total, the code `HELALUNE10`, shade choice, and checkout all run in the browser without JavaScript. Orders confirm on the page. Card numbers are never collected.

## Run

From this folder:

```bash
npm install
npm run dev
```

Open http://127.0.0.1:43123

To regenerate the pages after editing `build_site.py`:

```bash
python3 build_site.py
```

## Pages

Home, shop (with category filters, including an empty fragrance state), ten product pages, bag, checkout, order confirmation, journal, atelier, account, contact, shipping, returns, questions, and privacy.
